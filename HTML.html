- declaration defines that this document is an HTML5 Document - element is the Root Element of an html page - element contains the Meta information about the html page element specifies a title for the html page (shown in the browser’s title bar or page’s tab) <body> - element defines the document’s body - container for all the Visible <h1> - element defines a Large Heading <p> - element defines a Paragraph <html lang=”EN”> → Specifies Language of HTML Document An HTML Element is defined by a Start Tag, some Content and an End Tag <TagName> Content Goes Here… </TagName> An HTML Element is everything from the Start Tag to the End Tag Visualization of HTML Page Structure The Content inside the <body> section will be displayed in a browser. The Content inside the <title> element will be shown in the browser’s title bar or in the page’s tab Web Browser = Reads HTML Document and Displays Content All HTML Documents must start with a document type declaration <!DOCTYPE html> Represents the Document Type and Helps the Browser display the web pages correctly Not Case Sensitive Declaration for HTML5 The HTML Document itself begins with <html> and Ends with </html> The Visible Part of the HTML Document is between <body> and </body> HTML Headings - Defined with the <h1> to <h6> Tags <h1> - Most Important <h6> - Least Important HTML Paragraphs - Defined with the <p> Tag <p>This is a paragraph.</p> <p>This is another paragraph.</p> HTML Links - Defined with the <a> Tag <a href="https://www.w3schools.com">This is a link</a> Link’s destination is specified in the ‘href’ attribute Attributes - Used to provide additional information about HTML Elements HTML Images - Defined with the <img> Tag The Source File (src), Alternative Text (alt), width, and height are provided as Attributes <img src="w3schools.jpg" alt="W3Schools.com" width="104" height="142"> HTML Attributes → Additional Information about the HTML Element (above width + height) Specified in Start Tag Name/Value Pair ex) <img alt=”Alternative Text if Image Cannot be Displayed”> Style Attributes: Used to Add Color, Font, Size, Different Elements of Style <p style=”color:red;”> Red Paragraph </p> Title Attribute = More Information about Element HTML Heading → Change Font Size <h1 style=”font-size”60px;”> Heading 1 </h1>
